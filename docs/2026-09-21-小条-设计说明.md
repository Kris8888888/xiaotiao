# 小条 · 设计说明（2026-09-21）

## 目标
macOS 菜单栏小应用，在桌面上用一个置顶、半透明、不抢焦点的小条实时显示自选股（A 股 + 美股）的现价和涨跌幅。核心诉求是「隐蔽」：小、安静、鼠标穿透、一键隐藏、可伪装成时钟或一串数字。大小、透明度、字体、配色、方向可调；股票代码自己配。

## 不做什么
- 不做 K 线、盈亏、新闻、交易。
- 不做港股（免费接口延迟 15 分钟，先不接）。
- 不做账号体系；数据全走公开行情接口。

## 数据
- 主源：腾讯 `https://qt.gtimg.cn/q=sh600519,usAAPL`，GBK 文本，字段用 `~` 分隔：[1] 名称 [3] 现价 [4] 昨收 [30] 时间 [31] 涨跌额 [32] 涨跌幅。A 股与美股同一接口同一格式。
- 备源：东方财富 `push2.eastmoney.com/api/qt/ulist.np/get`（secid：沪 1.、深 0.、美 105./106./107.）。
- 请求绕过系统代理（这台 Mac 常挂 Clash；行情站是国内站，直连最稳）。
- 刷新：任一自选股所属市场在交易时段 → 快（默认 3 秒）；否则慢（默认 60 秒）。A 股 9:15–11:30 / 13:00–15:00 北京时间；美股 9:30–16:00 纽约时间（含夏令时）。
- 代码识别：6 位数字按首位判沪深（6/9/5→sh，0/3/1→sz，4/8→bj）；字母→美股；`sh/sz/us/hk` 前缀原样接受。

## 结构（Swift + SwiftUI，AppKit 管面板与菜单栏）
| 模块 | 职责 |
|---|---|
| QuoteService | 拉行情、解析、备源切换 |
| Market | 交易时段判断、刷新间隔 |
| Overlay | NSPanel 置顶面板：穿透、拖动、跨 Space、盖全屏应用、位置记忆、自适应尺寸；TickerView 三态渲染 |
| HotKey | Carbon 全局快捷键（不需要辅助功能权限） |
| AppState | 设置、定时器、菜单栏菜单、设置窗口、悬停探测 |
| SettingsView | 股票 / 外观 / 隐蔽 / 通用 四页，改动即时生效（所见即所得） |

## 隐蔽机制
- 鼠标穿透默认开：`ignoresMouseEvents = true`；菜单栏「解锁拖动」临时关掉。
- 悬停探测用全局 `mouseMoved` 监听 + 判断点在面板内，穿透状态下也能工作。
- 一键隐藏：快捷键（默认 ⌃⌥S）+ 菜单。伪装切换：快捷键（默认 ⌃⌥D）。
- 伪装：时钟（显示 HH:mm 与星期，悬停或快捷键露出行情）/ 纯数字（去名字、箭头、百分号）。
- 面板不出现在 Dock、不出现在 Cmd-Tab、不出现在 Mission Control 缩略图之外的任何地方（LSUIElement）。

## 视觉
- 像系统 HUD，不像行情软件。默认「墨玻璃」：底 rgba(20,22,26,0.72)，文字 #E8E6E1（暖白）。亮色底 rgba(246,247,245,0.85) + 墨 #1B2430。可无底（文字加软阴影）。
- 涨跌：默认单色，只用 ▲▼；可选朱砂 #C8553D / 松绿 #4F8A6B（红涨绿跌）或反过来。饱和度压低，无荧光，无渐变。
- 字：SF 等宽数字为默认；备选圆体、衬线（New York）。价格 13pt 中粗，别名和涨跌幅 11pt，整体按缩放系数走。
- 排版：横条（默认）项之间用 1px 30% 透明的细竖线分隔；竖列每股一行。三种状态共用同一套边距和字号，切换不变形。

## 分发
build.sh 出通用二进制 .app + dmg，ad-hoc 签名；首次打开右键「打开」。

## 1.1 追加（2026-09-21）
- 刷新：默认 1 秒（源 3 秒一档），失败退避 3/10/30 秒，隐藏时按休市间隔。
- 拖动：默认不穿透可直接拖；穿透时 ⌥+拖（全局鼠标监听）。

- AppSettings 改为兼容式 init(from:)，加字段不重置用户设置。
